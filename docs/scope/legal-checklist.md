# 邀请用户前的法律与合规核查任务

- 日期：2026-09-24（W0 Day 5 立项）
- 截止：**W7 Day 4** 备齐资料；没完成就暂停邀请（计划第 9 节）
- 注意：这是一份**待办清单，不是法律意见**。适用哪些义务取决于运营主体所在地、服务器位置和目标用户所在地区，需要本人核实，必要时咨询律师。

## 先要回答的问题

- [ ] 运营主体：个人还是公司？注册在哪里？
- [ ] 服务器与数据存储在哪个地域？（ADR 0007）
- [ ] 目标用户在哪些国家或地区？是否面向未成年人？
- [ ] 是否收费？（MVP 不收费，但以后会影响条款）

## 按地区可能涉及的事项（逐项核实是否适用）

| 情况 | 可能涉及 |
|---|---|
| 在中国大陆运营，或服务器在大陆 | ICP 备案；提供网站托管服务可能需要增值电信业务经营许可证；网络安全与个人信息保护相关法规；内容管理义务。**影响很大，应当最先确认** |
| 面向欧盟 / 英国用户 | GDPR / UK GDPR：处理依据、数据主体权利、数据处理协议、跨境传输 |
| 面向美国用户 | DMCA 的通知与删除流程和指定代理人；COPPA（13 岁以下） |
| 托管用户内容（通用） | 平台责任豁免的条件：知道违法内容后及时处理的流程 |

## 必须准备的用户可见文档（W7 Day 4）

- [ ] 服务条款（ToS）
- [ ] 隐私政策：收集什么（邮箱、IP、日志）、为什么收集、保留多久、谁会处理（邮件、存储、托管供应商）、用户有哪些权利
- [ ] 可接受使用政策（AUP）：禁止钓鱼、恶意软件、侵权、违法内容；违反后怎么处理
- [ ] 举报与投诉渠道：谁可以举报、多久回应、怎么处理（与 W6 Day 4 的举报入口对应）
- [ ] 版权投诉流程（如果适用）
- [ ] 数据删除流程：用户删除账号后，数据库记录和对象什么时候真正删除（和备份保留期一致）
- [ ] 公开的联系方式

## 实施时要落到产品里的点

- [ ] 注册时明确同意条款，并记录同意的版本和时间
- [ ] 日志和 IP 的保留期写进隐私政策，并在系统里真正执行
- [ ] 暂停站点时保留证据（W7 Day 1），保留多久要符合法规
- [ ] 产品名称、Logo、视觉和文案都是自己的（计划第 10 节），不使用 Nekoweb 的商标或素材
