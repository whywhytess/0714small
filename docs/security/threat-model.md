# 最小威胁表 v1

- 日期：2026-09-24（W0 Day 2）
- 范围：MVP（见 [Scope Freeze](../scope/mvp-scope-freeze-v1.md)）
- 更新时机：每个涉及认证、路径、租户隔离、发布的 PR；每周 Gate 前复核

## 资产

| 资产 | 为什么重要 |
|---|---|
| 控制面 Session / Cookie | 拿到它就能以用户身份改写站点 |
| 用户密码哈希、邮箱 | 个人数据；泄露会导致撞库 |
| 站点文件（草稿与部署） | 用户内容；被篡改就等于站点被劫持 |
| 发布指针 `current_deployment_id` | 决定线上内容 |
| Admin 权限 | 可以暂停任何站点 |
| 云凭据、数据库凭据 | 拿到就能接管整个平台 |
| 备份 | 最后的恢复手段；本身也包含敏感数据 |

## 信任边界

```
[访问者浏览器] ──(不可信 HTML/JS)──► *.sites-example.net ──► Gateway(只读) ──► DB(ro) / S3(ro)
[站主浏览器]   ──(Cookie + Origin)──► app.example.com    ──► Web/API(读写) ──► DB / S3
[运营账号]     ──► Admin（控制面内，按角色授权 + 审计）
[CI / 部署]    ──► 云账号（只有本人持有生产凭据）
```

## 威胁与控制

| # | 威胁 | 入口 | 控制措施 | 验证方式 | 周次 |
|---|---|---|---|---|---|
| T1 | 用户站点脚本读取或伪造控制面 Cookie | 站点域 | 不同注册域；`__Host-` host-only Cookie（ADR 0001） | 真实浏览器从站点域尝试读写 Cookie | W3 D4 |
| T2 | 站点脚本向控制面发起写请求（CSRF） | 站点域 → API | Origin 校验 + SameSite；站点域不在允许列表 | 伪造请求测试 | W1 D4 |
| T3 | 越权：用 A 的会话读写 B 的站点或文件 | API | 每个入口都校验 `owner_id`/`site_id`；统一的授权 helper | 双账号遍历所有接口 | W2 D4、W8 D3 |
| T4 | 路径穿越，读取别的站点或未发布文件 | Gateway / API | 只解码一次 + 拒绝非法段；按 `deployment_id` 查清单；对象键不含用户路径 | 共享测试向量（TS + Go） | W2 D2、W3 D5 |
| T5 | 伪造 Host 访问内部服务或别的站点 | Gateway | Host 白名单正则；无效 Host 返回 404；健康检查用单独端口 | Host 测试向量 | W3 D1 |
| T6 | 发布到一半，线上出现混合版本或空站 | 发布 | 不可变清单 + 事务切换 + 站点锁 + `operation_id`（ADR 0006） | 故障注入：存储失败、DB 失败、并发、重复点击 | W5 D2 |
| T7 | 暴力破解密码、撞库 | 登录 | 限流（IP + 账号）；登录失败不泄露账号是否存在；稳健的密码哈希 | 暴力尝试测试 | W1 D4 |
| T8 | Session 被盗后长期有效 | Cookie | 只存哈希；设置过期；登出、改密、封禁时撤销 | 撤销测试 | W1 D3 |
| T9 | 平台页面里的 XSS（站点标题、简介、标签） | Explore / 个人页 | 输出一律转义；不渲染用户 HTML；设置 CSP | 注入样例 | W6 D2 |
| T10 | 上传超大或超多文件，拖垮存储和费用 | 上传 | 单文件、文件数、总空间配额；请求体大小上限 | 超额测试 | W2 D4、W7 D2 |
| T11 | 恶意内容托管（钓鱼、恶意软件） | 站点 | 举报入口；Admin 暂停（保留证据）；条款和 AUP | 模拟滥用站点 | W6 D4、W7 D1 |
| T12 | Gateway 被攻破后可以写数据或读用户表 | Gateway | 只读 DB 角色，只能读 3 张表；S3 只读凭据 | 权限集成测试 | W0 D3（角色）、W3 D1 |
| T13 | 密钥被提交到公开仓库 | Git | `.gitignore`；CI 密钥扫描；`.env.example` 只放假值 | CI gitleaks | W0 D4 |
| T14 | 误删或勒索导致数据丢失 | 运维 | PITR + S3 版本控制；备份凭据单独存放；演练恢复 | 隔离环境恢复演练 | W7 D3 |
| T15 | Admin 权限滥用或被盗 | Admin | 只允许指定账号；每项操作写审计；暂停而不删除 | 审计记录检查 | W7 D1 |
| T16 | 依赖库的供应链风险 | 构建 | 锁文件；CI 使用 `--frozen-lockfile`；最小依赖；定期更新 | CI | W0 D4 |

## 暂不处理（记录在案）

- 同一站点域内的站点之间 Cookie 互相可见：静态站点可以接受；V2 评估 PSL。
- DDoS：交给 Cloudflare；MVP 不自建防护。
- 全网内容自动扫描：延期（Scope Freeze 第 3 节）。
