## PR #1 第一次 CI 失败：MinIO 镜像无法拉取

- 结果：Secret scan、TS、Go 三个 job 通过；**DB/storage integration 失败**，报错 `unauthorized: access to the requested resource is not authorized`（拉取 `quay.io/minio/minio`）
- 原因：MinIO 镜像在 quay.io 上也已无法匿名拉取（用匿名 token 请求 manifest 返回 401）。本机能跑，只是因为旧项目 `0714space` 留下了同一个镜像的缓存；Day 3 那次 `docker pull` 的“成功”其实是命中了缓存
- 教训：验证镜像能否拉取，要在没有缓存的环境里做，或者直接检查 registry
- 处理：换成 `rustfs/rustfs:1.0.0`。换之前用 AWS SDK 实测了建桶、版本控制、Put/Get/Head/List/Delete、删除标记、`If-Match`/`If-None-Match`（412），全部符合预期。Compose 服务改名为 `s3`，变量改为 `S3_*`；ADR 0005 已更新
